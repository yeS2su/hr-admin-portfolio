# HR-Admin Workspace

인사·총무 업무를 사람, 일정, 자산, 비용 단위로 관리하는 웹 워크스페이스 포트폴리오입니다.

이 저장소에는 실제 회사 자료나 개인정보를 포함하지 않았습니다. 로컬 데모는 `scripts/seed-dev.ts`가 만드는 가상 사용자와 가상 업무만 사용합니다.

## 주요 기능

- 채용·입사 업무공간
  - 입사 체크리스트
  - 이력서 송부 체크
  - 면접 일정과 캘린더 보기
  - 경영진면접 관리
  - 면접관 가능일 입력, 이력서 연락처·이메일 추출 보조
- 총무관리
  - 총무비용 월간 캘린더와 완료 상태
  - 자산관리대장과 반납기한 확인
  - 방문증 관리
  - 특허 납부 상태 관리
- 업무공간
  - 일간·주간·월간·연간 업무
  - 개인 업무공간 수정 권한과 활동 기록
- 엑셀 다운로드
  - 웹 화면은 업무 입력용으로 사용하고, 필요한 결과만 XLSX로 내려받습니다.

## 기술 구성

- TypeScript
- Cloudflare Workers
- Hono
- Cloudflare D1(SQLite)
- Vitest

## 로컬 실행

```powershell
npm.cmd install
npm.cmd run db:migrate:local
npm.cmd run seed:local
npm.cmd run dev
```

실행 후 표시되는 로컬 주소를 브라우저에서 엽니다. 시드 데이터는 포트폴리오 확인용 가상 데이터입니다.

## 검증

```powershell
npm.cmd run check
```

실제 배포에서는 별도 인증·권한 설정과 데이터 보안 검토가 필요합니다. 이 저장소는 포트폴리오와 로컬 데모를 위한 공개용 코드입니다.
