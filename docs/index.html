인사·총무 실무자가 AI를 활용해 만든 작업물

HR × AI Works.

반복되는 실무를 줄이고, 입사자 경험을 더 좋게 만들기 위해 AI와 함께 만든 결과물을 모았습니다. 필요한 기준과 방향은 직접 정하고, 구현과 시안 작업에 AI를 활용했습니다.

01

HR-Admin 업무관리 웹앱

파일을 오가며 확인하던 업무를 한곳에서 관리할 수 있도록 만들었습니다. 실무에 필요한 항목과 처리 기준을 정하고, AI로 구현한 화면과 기능을 직접 확인하며 다듬었습니다.

사용 대상
인사·총무 담당자
직접 정한 부분
입력 항목·업무 규칙·처리 순서
사용 기술
TypeScript · Hono · Cloudflare Workers · D1

주요 기능

  • 채용·입사입사 체크리스트, 이력서 송부 체크, 면접 일정, 경영진면접 관리
  • 업무공간팀·개인 업무를 분류·마감일·처리 상태로 관리
  • 총무관리총무비용, 자산관리대장, 방문증 관리, 특허관리
  • 기존 기록 검색이전 업무일지를 시트와 내용으로 검색
프로젝트 상세 페이지 보기 ↗

동작 시연 영상과 메뉴별 상세 화면은 상세 페이지에서 볼 수 있습니다. 모든 화면은 가상 데이터로 구성했습니다.

02

최종합격 안내 메일 리디자인

합격자가 처음 받는 회사 메일을 정보 전달용 표에서 환영의 첫인상을 주는 메일로 바꿨습니다. 디자인 방향과 문구를 직접 정하고, 시안 제작과 HTML 코딩은 AI(Claude)와 함께 진행했습니다.

대상
최종 합격자
직접 정한 부분
레이아웃·색감·문구·캐릭터 연출
발송 환경
Outlook · 사내 그룹웨어

개인정보는 가상 이름(홍길동)으로 바꿨습니다.

무엇을 바꿨나

항목기존변경
첫인상‘채용전형안내’ 범용 배너회사 캐릭터 데솔이와 ‘WELCOME TO DATASOLUTION’ 배너
정보 구조성함·일시·장소·서류를 한 표에 나열인사말 → 입사 정보 → 구비 서류 순서의 섹션 구성
가독성항목명과 값의 구분이 약함아이콘 제목, 회색 항목명·진한 값, 행 구분선
운영 편의매번 전체를 다시 편집이름과 입사 정보 4개 항목만 텍스트로 수정, 나머지는 이미지로 고정

작업 과정에서 해결한 문제

  • Outlook에서 서식이 깨지는 문제Outlook은 메일을 Word 엔진으로 그려 색·줄 간격·글머리표가 바뀝니다. 바뀌면 안 되는 부분은 이미지로, 사람마다 달라지는 부분만 텍스트로 나눠 구성했습니다.
  • 그룹웨어에서 생기는 여백스타일이 제거되는 환경에서도 이미지 사이 틈이 생기지 않도록 HTML 기본 속성으로 배치를 고정했습니다.
  • 캐릭터 연출회사 로비의 캐릭터 사진을 오려 본문 박스에 손을 걸친 형태로 배치해 배너와 본문을 자연스럽게 연결했습니다.
03

신입사원 온보딩 페이지

입사 첫날부터 적응 완료까지, 신규 입사자가 겪는 질문에 답하는 노션 가이드북입니다. 담당자에게 반복해서 오던 질문을 주제별로 정리해 스스로 찾아볼 수 있도록 구성했습니다.

대상
신규 입사자
도구
Notion · Notion Sites
운영 방식
피드백을 받아 계속 보완하는 문서

페이지 구성

  • 👋 시작하기입사 첫날 체크리스트, 장비 세팅, 계정 생성
  • 🏢 우리 회사 이해하기회사가 하는 일과 사내 용어
  • 🧭 회사생활급여·연차·수습평가·휴가 사용 방법
  • 🤝 비즈니스 매너 & 커뮤니케이션메일·전화·보고·회의 기본 매너
  • 🗺️ 회사 주변 꿀팁맛집·카페·편의시설·출퇴근 팁
  • 💬 FAQ / 피드백자주 묻는 질문과 개선 제보 창구

빠른 찾기 안내

사내 규정과 내부 정보는 제외하고 페이지 구성만 소개합니다.

04

웰컴키트 포장 띠지
