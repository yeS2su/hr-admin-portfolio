01

HR-Admin 업무관리 웹앱

파일을 오가며 확인하던 업무를 한곳에서 관리할 수 있도록 만들었습니다. 실무에 필요한 항목과 처리 기준을 정하고, AI로 구현한 화면과 기능을 직접 확인하며 다듬었습니다.

05

임직원 주차할인 자동등록 웹앱

주차할인은 업체 관리자 계정으로 로그인해야만 등록할 수 있어, 임직원이 요청할 때마다 담당자가 대신 등록해 왔습니다. 업체 시스템이 내부적으로 사용하는 API를 확인해 연결하고, 임직원이 로그인 없이 개인 코드와 차량번호만으로 직접 등록하는 웹앱을 고안했습니다. 코드 작성은 Claude와 함께 진행했고, 차량 조회와 할인 적용이 실제로 동작하는지 직접 확인하며 실사용 가능한 수준까지 완성했습니다.

사용 AI
Claude
직접 정한 부분
등록 흐름·개인 코드 방식·적용 항목
사용 기술
Google Apps Script · Google Sheets

담당자가 업체 콘솔에 로그인해 대신 등록

  1. 임직원이 담당자에게 차량번호와 함께 할인 요청
  2. 담당자가 업체 관리자 계정으로 콘솔에 로그인
  3. 차량번호 4자리로 입차 차량 조회
  4. 할인 항목 2종을 하나씩 선택해 적용

직접 등록할 수 없었던 이유할인 등록은 회사에 발급된 업체 관리자 계정으로만 가능합니다. 이 계정으로는 크레딧 충전과 유료 할인까지 다룰 수 있어 임직원에게 공유할 수 없었고, 모든 요청이 담당자를 거쳐야 했습니다.

임직원이 로그인 없이 직접 등록

  1. 개인 코드와 차량번호 뒤 4자리 입력
  2. ‘할인 등록’ 버튼 클릭
  3. 조회부터 할인 2종 적용까지 자동 처리, 결과를 화면에 바로 안내

달라진 점업체 시스템의 API를 확인해 웹앱이 관리자 계정으로 대신 호출하도록 만들었습니다. 계정 정보는 스크립트 안에만 보관하므로 임직원은 계정 없이 직접 등록하고, 담당자가 요청을 받아 처리하는 과정이 없어졌습니다.

업체 콘솔은 실제 화면에 진행 순서를 표시했고, 웹앱 화면의 개인 코드와 차량번호는 가상 값입니다.

연결 구조

임직원개인 코드 + 차량번호 4자리
→
주차등록 웹앱Google Apps Script명단 시트에서 개인 코드 확인
→
업체 시스템 API로그인 · 차량 조회 · 할인 적용

업체 콘솔 화면이 호출하는 요청을 분석해 로그인·차량 조회·할인 적용 API를 확인하고, 웹앱에서 같은 순서로 호출하도록 구성

설계할 때 신경 쓴 점

  • 공용 코드 대신 개인 코드공용 코드는 외부로 유출될 수 있다고 판단해, 임직원 246명에게 각각 고유 코드를 부여하고 구글 시트 명단으로 관리하도록 했습니다.
  • 예외 상황 안내정기권 차량, 이미 할인이 적용된 차량, 뒷번호가 같은 차량이 여러 대인 경우를 구분해 안내 문구를 보여 줍니다.

무분별한 사용을 막기 위한 장치

방안내용상태
개인 코드 확인명단에 등록된 코드만 처리하고, 할인 내역 메모에 등록자 이름을 남김적용
코드별 사용 중지코드가 유출되거나 퇴사하면 명단에서 해당 코드만 사용 중지적용
할인 항목 고정크레딧이 들지 않는 2종(1시간 무료, 80% 할인)만 적용하고, 유료 할인은 웹앱으로 등록 불가적용
고객사 차량 분리고객사 차량은 웹앱 대상에서 제외하고, 고객사명·예상 출차시간·요청 직원을 적어 인사총무팀에 요청적용
본인 등록 차량만 처리인사총무팀에 미리 등록한 본인 자차 번호와 일치할 때만 할인 적용검토 중
등록 내역 관리일시·차량번호·이름·코드·처리 결과를 기록 시트에 남기고 월별 사용 현황 점검검토 중
사용 횟수 제한1인당 하루 등록 횟수에 상한을 두어 업무 외 반복 사용 방지검토 중
