03

기획 배경

업무일지와 면접 일정, 자산관리대장을 여러 스프레드시트에서 관리하던 방식에서 출발했습니다. 필요한 기록을 찾거나 수정할 때 파일을 오가는 과정을 줄이고자 했습니다.

기존 자료에서 필요한 항목을 골라 메뉴와 입력 화면을 정했습니다. 엑셀 다운로드는 유지하고, 입력과 수정은 업무별 화면에서 처리하도록 구성했습니다.

04

메뉴별 상세 화면

대분류와 메뉴를 선택해 실제 화면을 확인합니다.

입사 시기와 조직 정보를 한 화면에서 확인

연도·월로 입사자를 좁혀보고 개인 이메일과 고용형태, 부문·본부·팀을 확인합니다. 조직도 파일은 미리보기 후 선택목록에 반영합니다.

크게 보기 ↗

공고별 발송 현황을 날짜 단위로 관리

채용사이트별 공고 정보를 묶고, 날짜마다 O·△·지원자 없음으로 기록합니다. 표 영역에 좌우 스크롤을 제공하며 이메일을 자동 발송하지 않습니다.

본부·장소·결과를 한 행에서 확인

면접 정보에 본부와 세부 조직, 회의실 위치를 표시하고 결과는 합격·불합격·보류로 관리합니다. 수정은 행의 연필 아이콘으로 엽니다.

크게 보기 ↗

경영진 면접도 같은 일정 구조로 관리

지원자별 면접 시간과 장소, 본부, 결과 통보 여부를 확인하고 후속 메모를 남깁니다.

크게 보기 ↗

월별 총무비용을 날짜별로 확인

홈 화면의 달력에서 지급일과 비용 항목을 확인하고, 연필 아이콘으로 내용을 수정하거나 완료 상태를 바꿉니다.

크게 보기 ↗

자산 사용 현황과 반납 예정일을 한눈에

자산코드, 사용자와 사용기간을 목록에서 확인하고 반납 예정 자산을 찾습니다.

크게 보기 ↗

필요한 방문 정보와 반출·반납 상태 관리

사용기간과 출입 권한, 기안 여부를 확인합니다. 방문증 번호는 목록에서 숨기고 수정 화면에서만 확인합니다.

크게 보기 ↗

기안부터 납부까지 단계별로 확인

납부기한과 비용을 확인하고 기안 필요·기안중·기안완료·납부완료 상태를 선택합니다.

크게 보기 ↗
공통 기능 · 업무공간과 기존 자료 찾기 ＋

분류가 필요한 업무와 원본 기록 조회

업무공간에서 분류가 비어 있는 항목을 모아 내용은 그대로 두고 분류만 보완합니다. 업무일지 원본 기록에서는 시트와 단어로 이전 자료를 찾습니다.

이전 기록은 시트와 내용으로 검색

원본 자료의 시트 이름과 위치를 유지해 업무 기록을 찾아볼 수 있습니다.

포트폴리오 화면은 실제 웹앱을 가상 데이터로 캡처했습니다. 개인정보와 사내 자료는 포함하지 않았으며, 여기서 입력한 값은 업무 시스템에 저장되지 않습니다.

05

담당한 일

기존 자료를 검토해 필요한 항목과 입력 순서를 정했습니다. 화면을 직접 사용하면서 날짜, 마감, 완료 표시와 수정 방식을 조정했습니다.

코드는 AI 도구와 협업해 작성했습니다. 업무 규칙을 결정하고 구현 결과를 확인하는 역할을 맡았습니다.
